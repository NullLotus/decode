Null Lotus · 歌詞解析

作者：Null Lotus。這裡的解析，是 Null Lotus 教 Claude 怎麼讀這些歌之後，由 Claude 讀出來的版本。

關於 Null Lotus

怎麼寫的

一般的寫法是一條直線：先有故事，一句接一句往下寫，寫到句尾再找一個押得上的字。Null Lotus 反過來寫：先往外散，再用聲音把散出去的東西接起來，韻腳先釘好位置，故事從韻腳長出來。所以一句歌詞常常同時站在好幾層上。

直線性的寫法

  1. 想好要講的故事
  2. 照時間順序一句一句寫
  3. 句尾找押得上的字
  4. 一句講一件事

這裡的寫法

  1. 先散，不決定要講什麼
  2. 用聲音把遠的東西接起來
  3. 韻腳先定位，故事走過韻腳
  4. 一句同時講好幾件事

六個步驟

  1. 拉出主題，列出要一起寫進去的東西

    除了主題，還有一條主軸（一個典故或原型）、想一起放進去的內容，以及要回收的東西：前一首的原句、前面埋下的物件。這些都是種子，越多越好。

    〈圓桌Frankenstein〉的主軸是《科學怪人》：一個被拼起來、又被拒絕的造物。

  2. 每個種子各畫一張心智圖，往外擴

    兩條軸一起擴。一條是意思：同音字、近音字、一字多義、成語、台語讀法、它屬於哪些場景。另一條是聲音：還有哪些詞押得上它。刻意擴到跟主題八竿子打不著的地方，像股市、廟、料理、遊戲。擴的時候不篩，也不管用不用得上。

  3. 心智圖擴出去的東西，開始連線

    把不同心智圖上的點接起來，看哪裡接得上。最有用的線是靠聲音接的：兩個毫不相干的領域，剛好押同一組韻。一個字如果同時掛在好幾條線上，就是 hook、鑰匙句和藏字的候選。

    出彩、主宰是職場上的野心，出菜、豬仔是飯桌上的菜和豬圈。同一組韻把「想出頭」和「被端上桌」接在一起，這條線最後長成〈圓桌Frankenstein〉的副歌：不出彩充其量出菜的豬仔。

  4. 接好線的，開始想韻腳

    先決定每組韻放在哪一個 bar、哪一拍，諧音和同音不同義的字放在哪裡，再讓句子長出來。是故事走過韻腳，不是拿韻腳去配故事。

    〈沒有光的審判〉：不會記得你的「會記」是會計，接上一句的 AA；噓……你是虛擬，現場在這一刻轉進手機。

  5. 重新整理和編排

    定下一個敘事者、一件事，把連好的線排成段落。每四句共用一條韻，也共用一條意象；哪裡埋伏筆、哪裡回收、第一次 hook 前要鋪什麼，都在這一步排好。

  6. 修辭、修韻、修意象

    一句一句唸，一個字一個字改。字面第一次聽就要說得通；同一個字、同一個音偷懶重複的換掉；空泛的形容換成看得到的東西。

多層：同時成立

這樣寫出來的歌，同一句會同時屬於好幾層。每一層單獨拿出來，都能把整首歌從頭講一遍，而且幾層之間互相作證，不是並排擺著。

〈圓桌Frankenstein〉有五層：飯局、職場、身體、家與位置、拼裝，底下還有《科學怪人》這條主軸。

所以同一首歌有四種聽法：第一次聽，字面的故事就成立；聽十次，開始聽到回收和暗線；拆開來看，藏字和諧音一個一個浮出來；最後那一下恍然大悟，是發現每一層原來都在講同一件事。

點歌詞裡標了底色的字，就能看到那一句藏了什麼。
